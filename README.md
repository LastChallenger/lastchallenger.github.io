# Yudong Fan — Personal Website

A static academic homepage for https://lastchallenger.github.io/.

## Publish with GitHub Pages

1. Create a public repository named `lastchallenger.github.io` under `LastChallenger`.
2. Upload the contents of this directory to the root of its `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then **main / (root)** and save.

The site will be available at https://lastchallenger.github.io/ after deployment finishes.
No custom domain, build step, or dependencies are required.

## Edit and preview

Edit `index.html` and `style.css`; site images and the BOLT paper are in `assets/`. The downloadable CV is excluded from this public site.
Run `python3 -m http.server 8000` in this directory, then visit http://localhost:8000/.
